Agents Cookbook

A reusable Markdown prompt library for coding agents.

Use one sharp skill directly, wrap it in an agent role, or compose several prompts into an optional flow. OpenCode, Pi, or another compatible host owns execution and isolation.

Library model

skills/

The library core: standalone review, discovery, and reasoning methodologies.

agents/

Thin host-ready prompt wrappers around skills or coordinator roles.

flows/

Optional composition recipes. No duplicate reviewer intelligence.

protocols/

Portable evidence, context, and output conventions for compatible hosts.

Standalone means standalone

  • A compatible host can load one skill directly.
  • A user can invoke one reviewer wrapper directly.
  • subagent-router can route one focused configured reviewer.
  • Ping-Pong/Ping-Ping can compose the exact eight optional reviewers.
  • Adding a new skill does not silently add another mandatory workflow step.

Host boundary

Cookbook owns

Markdown prompts, methodology, role contracts, evidence conventions, and optional composition examples.

Host owns

Model execution, tools, sandboxing, filesystem/process/network isolation, delegation, sessions, and persistence.

OpenCode and Pi are supported consumers of the prompt library, not the product boundary.
