# Browser Demo

Open `index.html` directly in a browser to run the standalone stakeholder walkthrough.

## How To Start

1. Double-click `index.html`, or open it from your browser with File > Open.
2. Use the step buttons across the top to walk through the story.
3. Use the left and right arrow keys during a presentation.
4. Use Start over to reset the walkthrough to the first step.

The demo is self-contained. It does not need a dev server, network access, installed packages, or a build step.
